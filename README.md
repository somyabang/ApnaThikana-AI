# 🏠 ApnaThikana AI
### Bill ho ya bakheda, AI hai na!

**ApnaThikana AI** is a web-based project designed to make hostel and PG living easier by helping students organize shared expenses, estimate electricity costs, coordinate chores, and manage everyday responsibilities.

## 💡 The Problem

Hostel and PG students often face everyday challenges such as splitting bills, managing electricity expenses, coordinating chores, and resolving differences in shared living arrangements.

These small problems can create confusion and make student life more stressful.

## 🚀 Our Solution

ApnaThikana AI brings useful shared-living tools into one simple dashboard. It aims to help students make informed decisions, stay organized, and coordinate responsibilities more easily.

## ✨ Key Features

### 📊 Dashboard
View an overview of expenses, budgets, and activities.

### 🤖 AI Assistant
Explore suggestions for common hostel and PG situations through the assistant interface.

### 💡 Smart Savings
- Estimate electricity costs.
- Calculate expenses using entered values.
- Compare cost scenarios.
- Support better budgeting decisions.

### 🤝 Roommate Hub
- Organize shared expenses.
- Split costs between roommates.
- Coordinate chores.
- Keep track of roommate preferences.

### ✅ Action Centre
- Review proposed actions.
- Organize reminders.
- Keep agreements and activities accessible.

### ⚙️ Settings
Customize available settings and switch between light and dark themes.

## ▶️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/somyabang/ApnaThikana-AI.git
   ```

2. Open the downloaded project folder.
3. Open the main HTML file in a web browser.
4. Explore the Dashboard, AI Assistant, Smart Savings, Roommate Hub, Action Centre, and Settings.
